# Portal‑OS‑v3

Portal‑OS‑v3 is a multi‑engine, event‑driven operating surface built with React + Vite. It provides a unified runtime surface, an EventBus, and modular engines (SIM, XR, Identity Physics, Operators, Games).

This repository contains the source and runtime for Portal‑OS‑v3 and is designed for rapid development and CI-driven automation.

## Quickstart

Prerequisites:
- Node.js 18+ (LTS)
- npm

Install and run locally:
```bash
npm ci
npm run dev
