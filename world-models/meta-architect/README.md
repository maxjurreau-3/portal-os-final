# Meta‑Architect

High-level layer that synthesizes substrate outputs into architected artifacts:

- canon: coherence fields → canonical source-of-truth
- narrative: awareness streams → story / timeline
- architecture: unified field → system architecture snapshots
- identity lineage: quantum suite → signed identity provenance

API:
- buildArchitecturalDigest(opts) -> { canon, narrative, architecture, identityLineage, notes }
